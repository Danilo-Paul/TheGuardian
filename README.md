A Tecnologia por trás do The Guardian
Para oferecer uma experiência de ponta e recursos inteligentes, o desenvolvimento do software contou com a integração de ferramentas avançadas:
Gemini & Google AI Studio: Utilizados para alimentar a inteligência do sistema, permitindo o funcionamento do módulo Guardian, que oferece dicas personalizadas e auxilia na interpretação dos dados financeiros do usuário
.
NotebookLM: Empregado na organização e síntese da base de conhecimento do projeto, garantindo que as funcionalidades de auxílio ao planejamento sejam fundamentadas em dados estruturados.
Stitch - Projects: Atuou como a espinha dorsal para a estruturação e organização do desenvolvimento do software, permitindo uma integração fluida entre os módulos de análise e gestão.

Funcionalidades Principais
O The Guardian posiciona-se como uma "fortaleza financeira", oferecendo:
Gestão Completa: Controle total sobre receitas, despesas e saldo disponível em um único lugar
.
Patrimônio Imobiliário: Módulo especializado para gerenciar imóveis, aluguéis e despesas de manutenção com precisão
.
Metas Dinâmicas: Criação de objetivos financeiros vinculados a índices de correção reais (como CDI, IPCA ou Selic) para acompanhar o crescimento real do patrimônio
.
Projeções Inteligentes: Visualização do futuro financeiro através de entradas e saídas previstas, permitindo um planejamento antecipado de até 6 meses
.
Análises Detalhadas: Gráficos de rendimento patrimonial e comparativos de receita versus despesa para uma visão analítica do desempenho mensal e semestral
.

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
